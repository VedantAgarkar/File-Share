## Data Flow

1. **Selection**: User selects a file or folder in the UI. Folders are zipped into a temporary archive.
2. **Server Initiation**: A background thread starts the `ThreadedTCPServer`.
3. **Authentication**: A 4-digit PIN is generated/entered. A QR code containing the server URL is displayed.
4. **Client Connection**: Client connects via browser.
5. **Verification**: client enters PIN.
6. **Transfer**:
   - **Send Mode**: Server streams file to client.
   - **Receive Mode**: Server accepts multi-part POST upload from client.
7. **Cleanup**: Temporary files (zips) are removed and server is shut down after transfer or cancellation.
